AI-Based Medical Chatbot

Project Overview

The AI-Based Medical Chatbot is a web application designed to provide users with an interactive way to explore health-related information. It uses machine learning and web technologies to process user inputs and support medical information or disease prediction, depending on the implemented functionality.

 Objectives

- Provide a simple, user-friendly chatbot interface.
- Process user queries through a web application.
- Integrate a trained machine learning model.
- Explore the use of AI in healthcare-related applications.

Technologies Used

- Python – Core programming language
- Django – Web application framework
- Machine Learning – Model-based prediction
- TensorFlow / Keras – Model integration
- HTML, CSS, JavaScript – Web interface (if used in the project)
- Dataset – Data used by the project (see the "Dataset" folder)

 Installation and Setup

1. Clone this repository:
   
   git clone https://github.com/navyasrivudatha9944/An-AI-based-medical-chatbot.git

2. Open the project directory:
   
   cd An-AI-based-medical-chatbot

3. Create and activate a Python virtual environment:
   
   python -m venv venv

4. Install the required dependencies:
   
   pip install -r requirements.txt

5. Run the Django development server:
   
   python manage.py runserver

6. Open the local URL displayed in the terminal in your web browser.

Note: The dependency versions and setup instructions may need adjustments depending on your Python version and project configuration.
